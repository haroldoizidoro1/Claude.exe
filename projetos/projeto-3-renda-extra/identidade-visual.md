## Regras de uso (importante para vender)
1. **Não usar os logos** da Amazon, Shopee ou J&T no painel. O logo é marca registrada e o painel não é oficial.
2. Usar só a **paleta como referência** e o nome do cliente como texto (ex.: "Operação Shopee").
3. Todo painel mostra: "Demonstração com dados fictícios. Não é afiliado a Amazon, Shopee ou J&T."
4. A marca em destaque no painel é a **sua** (do serviço), não a do marketplace.

## Painéis do laboratório que podem virar molde (artefatos)
- Torre Amazon, Operação Amazon na MR → molde do painel Amazon

Atenção: esses artefatos têm dados reais da empresa. Ao reaproveitar, copiar só o layout e trocar TODOS os dados pelas bases de `dados-ficticios/`.
